# map-script

国土地理院の地図タイルを取得して夢洲周辺の地図画像を作成し、万博公式のゾーン分け・色分けオーバーレイを合成するスクリプト群

## 使い方

```bash
pip install -r requirements.txt

# 1. 国土地理院標準地図タイルの取得とベース画像合成
python fetch_map.py

# 2. 万博公式マップ（会場図）準拠・全パビリオンピン付き色分けマップ生成
python generate_zones.py
```

## 出力ファイル

- `yumeshima_map.png`: 国土地理院タイルから合成したベース地図 (3139x2472)
- `yumeshima_map_zones.png`: 万博公式マップ（会場図）準拠の高精度ゾーン分けマップ（全97パビリオン公式ピン＋主要ランドマーク入り）
- `zone_polygons.geojson`: 各ゾーンのGeoJSONポリゴンデータ
- `zone_polygons_pixels.json`: 各ゾーンの画像内ピクセル座標データ
- `zone_bounds.json`: 各ゾーンの緯度経度・ピクセルバウンディングボックス
- `pavilions.json`: 最新のAPIパビリオンキャッシュ

## ゾーン定義 (万博公式マップ・会場図準拠)

| コード | ゾーン名 | 公式カラー | 対象エリア / 主な施設 |
|:---:|:---|:---:|:---|
| **C** | コネクティングゾーン | `#00A3E0` | 大屋根リング内側・北側海外パビリオン (co01〜co22) |
| **S** | セービングゾーン | `#F39800` | 大屋根リング内側・西側海外パビリオン (sv01〜sv20) |
| **P** | エンパワーリングゾーン | `#00A650` | 大屋根リング内側・東側海外パビリオン (emp01〜emp29) |
| **F** | 静けさの森ゾーン | `#84BD00` | 大屋根リング中央（水盤「いのちの池」・森林エリア） |
| **X** | シグネチャーゾーン | `#9B499A` | 静けさの森南縁パビリオン (sig01〜sig08) |
| **WP** | ウォータープラザ | `#38C1E8` | 大屋根リング南側親水海域（内海） |
| **W** | 西ゲートゾーン | `#0068B7` | 西エントランス広場、西通り沿いパビリオン (W01〜W10)、EXPOメッセ (W11)、風の広場通路 |
| **E** | 東ゲートゾーン | `#E60012` | 東エントランス広場、東通り沿いパビリオン (E01〜E10)、日本館 (E01)、EXPOホール (E11)、ナショナルデーホール (E12) |
| **L** | フューチャーライフゾーン | `#A4D233` | 会場北西端（未来の都市 L01、Vertiport L08、EXPOアリーナ「Matsuri」 L06等） |

※交通ターミナル（夢洲第1交通ターミナル・バス乗り場島、夢洲第2交通ターミナル・駐車場）および大屋根リング本体（木造ハッチング）は公式マップに準拠してゾーン着色から除外し、下地地図の道路・木目を鮮明に保持しています。
