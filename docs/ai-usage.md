# AI活用の記録

プロダクトのAI機能と、開発を支援するAIの利用を分けて記録する。この文書は確認できた範囲の記録であり、開発期間全体のプロンプト・実行履歴を網羅するものではない。

## プロダクト内での利用

| 利用箇所 | AIの役割 | アプリ・サーバーが担う処理 |
| --- | --- | --- |
| 周辺の建築ガイド | Vertex AIのGeminiで、登録資料から日本語の短い説明文を生成 | セッションの認可、位置・向きによる対象選択、入力資料の組み立て、出力の検証、固定文への切替 |
| ガイドの読み上げ | Gemini TTSで、確定した本文を音声化 | WAVの検証、WSSでの分割配信、端末での再生・停止・一時ファイルの破棄 |

ガイドは利用者がボタンを押したときに生成する。資料は命令と分離して渡し、登録されていない事実や撮影の正解位置を加えないよう指示する。この指示だけで事実の正確性を保証するものではない。本文・音声をDBやGCSへ永続キャッシュせず、生成失敗時は固定文、音声失敗時は本文の表示を継続する。

AIは撮影の採点に使わない。採点は位置・yaw・pitchの差に基づくサーバー側の決定的な計算で、ガイドの対象選択も登録された構造物の距離・方向に基づく。

## 更新時に残す情報

作業ごとに日付、利用ツール、目的、採用した成果物、確認方法、残る制約を記録する。プロンプトを記録する場合は、認証情報や非公開の個人情報を含めない。テストの成功だけで、AIの説明の正確性や利用者への効果まで確認済みとは扱わない。
