# 会場モデルの区画分割・遠景LOD（scene_tiles）

会場GLB（`app/assets_src/models/merged_model_draco.glb`）を区画に分け、
近景用の高精細モデル・遠景用の簡略モデルと、区画範囲の `manifest.json` を生成する。
出力は `app/assets/models/tiles/` で、アプリはここだけを同梱・読み込みする。

加工元のGLBは `assets/` の外に置き、同梱しない。flutter_sceneのビルドフックは
`assets/` 以下のGLBをすべて `.fsceneb` へ変換し、元ファイルが消えたときだけ
生成物を削除するため、`assets/` に残すと以前の生成物が同梱され続ける。

## 再生成

Node.js は app の `mise.toml` で 26.13.0 に固定している。依存は `package-lock.json` で固定している。

```sh
mise //app:tiles:generate   # app/assets/models/tiles を作り直す
mise //app:tiles:test       # 単体テストと、生成済み区画の三角形・材質・範囲の検査
```

直接実行する場合は次のとおり。

```sh
cd app/tool/scene_tiles
npm ci --ignore-scripts   # sharp は同梱のビルド済みバイナリを使う
npm run generate          # app/assets/models/tiles を作り直す
npm test                  # 単体テストと、生成済み区画の三角形・材質・範囲の検査
```

同じ入力と既定値なら、出力はバイト単位で同じになる。
`node generate.mjs --help` で既定値を、`--tile-size 150` のように指定すると値を変えられる。
既定値を変えたら、下の記録とPRの説明を更新する。

manifest には加工元GLBの SHA-256（`sourceSha256`）を記録する。加工元を差し替えて
再生成を忘れると、`mise //app:test` の manifest のテストが失敗する。

## 加工の内容

| 項目 | 内容 |
| --- | --- |
| 座標 | GLBの頂点をそのまま使う（全ノードが単位行列であることを検査）。manifestの範囲はアプリの座標で、flutter_sceneのビルド時変換に合わせてZを反転する（`GltfCoordinatePolicy.bakeNative`）。`assets/collision.bin` の範囲（Z −602〜701）とも一致する |
| 区画 | アプリの座標で200m格子。区画以下の大きさのプリミティブ（建物1棟など）は範囲の中心の区画へ丸ごと入れ、区画より大きいもの（大屋根リングの4つと、建物・設備の共通材質の2つ）だけ三角形の重心で分ける。三角形は切断しない |
| 高精細 | 加工元と同じ三角形・材質・テクスチャ（512px JPEG）。Draco（位置16bit）で圧縮する |
| 簡略 | 0.5m格子の頂点クラスタリングで、潰れた三角形と重複を除く。法線の主軸の向き（±X・±Y・±Z）が違う頂点は同じ格子でも分け、箱の角で別の面の法線を引き継がないようにする。テクスチャは64px JPEG。Draco（位置14bit） |
| 除外 | 2頂点が同じ位置にある面積ゼロの三角形（描画されず、Draco圧縮でも除かれる） |

簡略化にmeshoptimizerを使わないのは、大屋根リングが非多様体の格子材で、
位相を保つ簡略化では誤差4mを許してもほとんど減らなかったため。
頂点クラスタリングの誤差は格子の対角（約0.87m）以下で、
高精細距離200mの境界では最大約4.5px（縦画角60°・縦1080px）になる。
同じ格子の頂点は最初の頂点のUVを引き継ぐため、UVの継ぎ目ではテクスチャがずれ得る。
細い部材が遠景で消える可能性もあり、写真の視点で見た目を確認する。

## 生成結果（既定値）

| | 加工元 | 高精細（33区画） | 簡略（33区画） |
| --- | --- | --- | --- |
| 三角形 | 1,250,848（うち面積ゼロ 26,311） | 1,224,537 | 610,962（50%） |
| GLB容量 | 11.98 MiB | 12.60 MiB | 4.45 MiB |
| 同梱される `.fsceneb` | 66.10 MiB | 69.95 MiB | 11.58 MiB |
| テクスチャ | 457枚・9,060万画素 | 479枚・9,640万画素 | 64px |

- 高精細のテクスチャ増加（+6%）は、区画をまたぐ大屋根リングの3枚が区画ごとに複製されるため。
- 同梱容量は、加工元の `.fsceneb` 66.1 MiB とGLB 12.0 MiB（従来は両方を同梱）の計78.1 MiBから、
  区画の `.fsceneb` 計81.53 MiB と `manifest.json` になる。
- 法線の向きで頂点を分けない場合は 579,831 三角形（47%）だった。陰影の崩れを避ける代わりに3ポイント増えた。
- `.fsceneb` はflutter_sceneの変換器（`importGltfToFsceneb`）で計測した。テクスチャは非圧縮RGBAで格納される。
